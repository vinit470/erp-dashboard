# erp-dashboard

Enterprise Infrastructure & Discom ERP Dashboard system with single-page operations hub, real-time telemetry filters, and multi-portal workflow tracking.

## Features
- **Single Page Operations Hub**: 4 core modules (Purchase, Store & Inventory, Work Order & Site, Billing & Invoicing) with dynamic ledger tables.
- **Workflow & Process Flow Tracing**: End-to-end multi-portal tracking connecting HO Billing Portal, Site Portal, PM Portal, PD Portal, Purchase Portal, and Store Manager Portal.
- **Live Inventory Ledger**: Real-time stock computation across stores, receipts, inwards, issues, and returns.
- **Detailed Reconciliation Reports**: LOA, BOM, DI, JMC, MRHOV, Billing and WIP tracking with export capabilities.

## Tech Stack
- React 18
- Vite
- Tailwind CSS
- Lucide React
